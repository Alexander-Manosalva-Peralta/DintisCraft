# 🎨 Frontend

Carpeta destinada al desarrollo de la aplicación frontend (React, Next.js, Vite, etc.) que se conectará con el backend de **Convex (`apiconvex`)**.

---

## 🌐 URLs del Backend (Convex)

- **Convex Cloud Deployment (Real-time DB / Hooks):**
  `https://colorless-anteater-240.convex.cloud`

- **Convex HTTP Actions (REST API):**
  `https://colorless-anteater-240.convex.site`

---

## 🚀 Instrucciones para el equipo Frontend

1. Inicializa tu proyecto dentro de esta carpeta (por ejemplo con `npm create vite@latest .` o `npx create-next-app@latest .`).
2. Instala el cliente de Convex:
   ```bash
   npm install convex
   ```
3. Configura tus variables de entorno con `NEXT_PUBLIC_CONVEX_URL=https://colorless-anteater-240.convex.cloud`.
